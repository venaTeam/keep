# Jira On-Prem Provider

`JiraonpremProvider` is a class that integrates with self-hosted Jira instances to manage issue tracking through Keep.

<AutoGeneratedSnippet />

## Connecting with the Provider
To connect with the Jira On-Prem provider and manage issues through Keep, follow these steps:

1. Obtain Jira Credentials: You will need either:
   - Username and Password for basic authentication
   - API Token for token-based authentication
2. Configure your Jira host URL (must be HTTPS)
3. Use the following YAML example to create an issue using the Jira On-Prem provider:

```yaml title=examples/issue_creation_example.yml
# Create an issue using the Jira On-Prem provider.
task:
  id: create-jira-issue
  description: Create an issue in Jira On-Prem
  actions:
    - name: create-issue
      provider:
        type: jiraonprem
        config: "{{ providers.jira-onprem-provider }}"
        with:
          project_key: "PROJ"
          summary: "Issue Summary"
          description: "This is the issue description"
          issue_type: "Task"
          priority: "High"
          labels: ["alert", "keep"]
```

## Update an Existing Issue

```yaml title=examples/issue_update_example.yml
# Update an existing issue in Jira On-Prem.
task:
  id: update-jira-issue
  description: Update an issue in Jira On-Prem
  actions:
    - name: update-issue
      provider:
        type: jiraonprem
        config: "{{ providers.jira-onprem-provider }}"
        with:
          issue_id: "PROJ-123"
          summary: "Updated Summary"
          description: "Updated description"
          priority: "Critical"
```

## Authentication Configuration

The provider supports the following authentication configurations:

- **host**: Your self-hosted Jira instance URL (HTTPS required)
- **user**: Jira username
- **password**: Jira password or API token
- **api_token**: Alternative to password for token-based authentication

## Scopes

The provider validates the following scopes:
- **BROWSE_PROJECTS**: Browse Jira Projects
- **CREATE_ISSUES**: Create Issues
- **EDIT_ISSUES**: Edit Issues (for updates)
