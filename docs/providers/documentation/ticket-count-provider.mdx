## Connecting with the Provider

1. Deploy or expose an HTTP endpoint that returns ticket counts in the expected JSON format:
   - `{"count": <number>}` – standard response
   - `{"Team not found": 0}` – optional response when the requested team is missing
2. Configure the provider in Keep and supply the `count_url` (must be reachable from the Keep backend).
3. (Optional) The widget can append query parameters (`team`, `state`, `detection`) – ensure your endpoint can parse and handle them.
